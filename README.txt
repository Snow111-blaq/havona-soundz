HAVONA SOUNDZ — WEBSITE STARTER
Tagline: Music Unites Us.

WHAT THIS BUILD INCLUDES
- Responsive cosmic/futuristic landing page, designed to work on mobile and desktop.
- Discover section with clearly labelled demo music cards.
- Artist interest form UI, signup UI, login UI, and trust/policy principles.
- Basic SEO description, accessible labels, responsive layout, and no external libraries.

IMPORTANT: THIS IS A FRONT-END PROTOTYPE, NOT A LIVE PRODUCTION SERVICE
- Login, signup, artist interest, music playback/downloads, and all forms are visual demos only. They do not send or store information.
- Do not enter real passwords or sensitive information in this demo.
- Demo track cards are not real releases and have no playable audio.
- Contact address is a placeholder and must be replaced with a verified address you control.
- A real site requires a backend, database, secure authentication, email verification, password reset, server-side role permissions, secure file storage, upload validation, backups, logging, and security testing.

OWNER ACCOUNT / SECURITY REQUIREMENTS
- Create the initial owner account through a private server-side setup process, not a public signup field.
- Store passwords using a reputable authentication provider or strong salted password hashing; never store plain-text passwords.
- Enforce roles server-side: owner/admin, artist, listener. Never rely on hiding buttons in the browser.
- Require MFA for the owner, secure recovery, rate limiting, session expiry, and audit logs for important admin actions.
- Never build a hidden unauthenticated “back door”; use a documented, secured owner dashboard.

BEFORE PUBLIC LAUNCH
1. Choose and register a domain; confirm the name and trademark availability in intended markets.
2. Select hosting and a backend/database/auth provider. Enable HTTPS and secure environment variables.
3. Create owner account privately and verify recovery/MFA.
4. Build the owner dashboard, artist profiles, release management, approval queue, and file upload pipeline.
5. Use licensed audio storage/streaming and rights-cleared music. Obtain permission for compositions, recordings, samples, artwork, and any cover versions.
6. Prepare legally reviewed Terms of Service, Privacy Policy, Copyright/Takedown policy, Artist/Distribution Agreement, royalty/payment terms, and community standards for target countries.
7. Define how artist identity, ownership, splits, tax/payment details, disputes, and takedown requests will be handled. Collect sensitive payment/tax details only when necessary and securely.
8. Do not promise guaranteed distribution or fixed royalties per stream. Distribution to Spotify, Apple Music, YouTube Music, etc. generally requires an eligible distributor/partner agreement and platform compliance.
9. Add contact/support channels, analytics with privacy controls, backups, monitoring, accessibility checks, and mobile/browser testing.
10. Test registration, recovery, upload permissions, copyright reports, admin actions, and deletion/export requests before launch.
